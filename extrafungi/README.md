# Extra Fungi — Brand Website

A minimalist, modern single-page rebrand for **Extra Fungi**, the family-owned
wild-mushroom company from Kočani, North Macedonia (founded 1988).

## Live preview

Published via GitHub Pages:
`https://growthradical.github.io/agencysite/extrafungi/`

## About the design

- **Positioning:** wild forest mushrooms, fruits & vegetables — foraged,
  processed, and exported to Europe (France, Italy, Spain, Germany).
- **Aesthetic:** editorial minimalism — deep forest green + warm cream paper +
  amber accent, `Fraunces` display serif paired with `Inter`.
- **Sections:** hero, story/heritage, product harvest, forest-to-table process,
  export markets, values, and a contact/CTA.
- **Tech:** a single self-contained `index.html` (inline CSS + JS). Photography
  loads from Unsplash as progressive enhancement, layered over designed color
  fallbacks, so the page always renders cleanly even offline.

## Editing

- Copy, contact details and product blurbs live directly in `index.html`.
- Contact email/site (`info@extrafungi.com`, `extrafungi.com`) are placeholders
  ready to swap for verified details.
- Replace the Unsplash image URLs with the company's own photography when
  available (search `images.unsplash.com` in the file).
